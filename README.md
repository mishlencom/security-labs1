# Лабораторна робота №1. Аналізатор безпеки паролів

Консольна програма на Python 3 (без зовнішніх залежностей). Працює повністю локально:
пароль та особисті дані не передаються в мережу і не зберігаються.

## Запуск
    python password_analyzer.py

Програма запитує ім'я, прізвище та дату народження (ДД.ММ.РРРР), потім
приймає паролі для перевірки (ввід прихований). Порожній рядок завершує роботу.

## Що перевіряється
- наявність імені/прізвища (кирилиця, транслітерація, зворотний порядок, leet-заміни: `1v@n`);
- фрагменти дати народження (рік, ДДММ, ДДММРРРР тощо);
- довжина, різноманітність символів, оцінка ентропії та орієнтовний час перебору;
- словникові слова та поширені паролі;
- клавіатурні й числові послідовності, повтори, шаблон «слово + цифри».

## Оцінка (1–10)
Довжина (до 3.5 б.) + різноманітність символів (до 2.5) + ентропія (до 2) +
бонус за відсутність слабких місць (до 2.5). Якщо знайдено персональні дані,
оцінка обмежується (макс. 5, або 4 при кількох збігах).

## Приклад
Вхід: пароль `ivan1995`, ім'я `Іван`, дата `15.03.1995`
Результат: 4/10; знайдено ім'я та рік народження; шаблон «слово + цифри».
